# Hub / shared memory is a blackboard, not a mind

*Macheng Shen · 2026-09-18 · public note*

## Claim types

- **Definition (stipulative):** For this note, a *mind* requires a locus where awareness intensity \(W\) can see a mode-gate (the “RealmGate” in our Consciousness Dynamics working sketch).
- **Hard result under that definition:** A shared memory hub with typed records and receipts but **no** such \(W\)-locus is a **blackboard / shelf**, not a mind.
- **Design hypothesis:** Useful multi-agent systems should keep the blackboard thin (records + receipts) and keep irreversible actions gated. Do not advertise the blackboard as a proto-planetary mind.

## What this is not

- Not a proof that planetary consciousness is impossible.
- Not a license to build blockchain/DAO/cloud sprawl from metaphor essays.
- Not a diagnosis of any person.
