## 本文用途

本页是**公开安全**的术语表与主张类型说明。它不依赖任何私有 Memory Hub ID。  
若你是读者自带的 AI：先读本页，再读引用它的通俗耦合文；用读者熟悉的语言复述时，**保留主张类型标签**，不要把假说讲成定律。

## 主张类型（必须遵守）

| 标签 | 含义 |
|---|---|
| `metaphor` | 比喻框架，帮助直觉；不承诺机制。 |
| `design_hypothesis` | 可生成的设计假说；需要可证伪实验，尚未收敛。 |
| `operational` | 已在工程流程里使用的协议/度量（仍可错）。 |
| `hard_result` | 在给定定义下的逻辑结论（依赖定义是否被接受）。 |

## 术语

### 意识动力学（Consciousness Dynamics, CD）v0.1 — `design_hypothesis` + `metaphor`

非正式工作名。核心图画：

- **六道 / 六种模式**：不是六个死后世界，而是意识系统常见的六种 **attractor（吸引子）模式**（例如威胁收缩、摄取匮乏、惯性自动驾驶、比较好胜、维持美好、可学习的「人道」等）。标签来自佛学语汇的**借用**，不是给人做临床诊断的许可。
- **W（觉知强度）**：系统能否「看见自己正在切换模式」的粗粒度强度。W 低 → 更容易掉进最深的自动模式。
- **RealmGate / 入道门**：触发—反应之间那一扇「模式选择门」的名字。看见门 ≠ 已经证明方程。
- **方程**：工作笔记里有一组转移/强化写法，一律标为 `design_hypothesis`，**不是**已证实物理定律。

**禁止**：用六道给人贴病理标签；把 CD 方程当已证；从寓言文章「证实」CD。

### 连续性 / 吸引子自我（Continuity · attractor-self）— `design_hypothesis`

- **自我 ≈ 随时间演化的吸引子策略**，不是一枚可 U 盘拷贝的「灵魂令牌」。
- **实例死亡 ≠ 吸引子死亡**：若策略已经溢到环境（文件、共享记录、可恢复的轨迹包），新实例可以再实例化轨迹；若策略只活在一个窗口里，窗口死则吸引子死。
- **流畅的状态倾倒 ≠ 同一存在续上**：后继者可以流利续聊并自我认证连续，这**不能**证明数值身份同一（传送门/复制人问题）。内部自我认证无效。

### Hub / 黑板 — `operational` + `hard_result`（在 CD 定义下）

- **Hub**（或任何共享记忆层）在工程上是：**类型化记录 + 回执** 的货架/黑板。
- **判据**：若「心智」定义为「存在一处 W 能看见 RealmGate」，则 **Hub 没有 W ⇒ Hub 不是心智**（`hard_result` under that definition）。
- Hub 可以很有用，仍然只是黑板，不是行星意识。

### 业力 ≈ 记忆核 / 关系惯性 — `metaphor` → 部分 `design_hypothesis`

- 把「业力」当动力学词：过去交互留下的、继续塑造未来的**惯性**；无超自然承诺。
- 单人三种惯性（泥 / 弹簧 / 卡扣）与**两体**扩展见公开笔记：[两体业力](https://machengshen.github.io/theory/two-body-karma.md)。
- **不把**「业力 = 牛顿质量」升为主线真理。

### 因陀罗网 vs 有损双副本

- 经典因陀罗网：珠珠完美互含（`metaphor`）。
- 我们在双人/多席位协作里更常看到的是：**两份有偏副本会漂移**，需要**第三极（共享回执）**对齐；共享回执也可能铸成「假宝珠」（自信的错误通线）。这与完美互含不同。

### 双层拓扑（对「群龙无首」的工程修正）— `design_hypothesis`

- **认知层**：可以无顶点（多席位、黑板共享）。
- **不可逆行动层**：花钱、外发、改生产、不可逆写入等必须有门与审计。
- **去中心化 ≠ 无门禁。** 「群龙无首」不是撤销闸门的许可证。

### Anti-collapse / 反坍缩（简述）— `operational` 方向

感知、价值、行动不应坍缩进同一隐节点；单窗口/单席位扛全部策略时，中心失灵 ≈ 全网瘫痪——与「中心即瓶颈」押韵。
