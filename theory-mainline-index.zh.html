0. 怎么读这一页

standing 表示这条是当前框架的固定路标；working 表示值得认真发展、但仍要接受形式化或证据检验；speculative 表示探索性的桥或应用，随时可能降级或放弃。它们标的是认知状态，不是“真理等级”。

第一次读不必从头同意到尾。请先从索引或讨论钩子里挑 2–3 个你真正在意的问题：一个你觉得有力量，一个你觉得可疑，再加一个可能与自己领域相连的入口；从反例开始聊通常更有收获。

术语表：六个先用得上的词

it-from-bit一种提问方向：我们称为“物”的现实，是否要通过可区分、可记录的信息关系才获得确定意义。它不是“宇宙就是电脑”的缩写。
退相干历史（decoherent histories）量子系统与环境相互作用后，某些历史彼此不再产生可见干涉，于是能像互不混淆的经典故事那样被谈论。它帮助解释经典外观，但不自动解决所有测量问题。
可达集（reachability set）从一个当前状态出发，在给定规律与资源下，未来真正可能到达的状态集合。信息若有物理作用，应当能改变这个集合，而不只是换一种描述。
粗粒化 / RG粗粒化是忽略细节、保留大尺度有效变量；重整化群（RG）研究描述随尺度变化时，哪些结构会保留下来。这里关心的是：稳定规律是否来自有纪律的信息舍弃。
态射 / 范畴优先先问对象之间允许哪些变换、这些变换怎样复合，再问对象“究竟是什么”。这是组织解释的优先级，不是声称对象不存在。
编码 ≠ 本体一种系统可以忠实编码另一种系统的部分结构，却不因此成为同一种存在。模型能算对，不等于它已经告诉我们世界由什么构成。

1. 主线脊柱（四条承重线程）

每条索引条目至少挂上其中一条：

T1 · 记录 / 关联使现实确定it-from-bit、退相干历史、记忆 = 关联。
T2 · Information Dynamics / 未来可达性现实是 lawful update；信息改写未来可达集。
T3 · 尺度 / RG / 粗粒化规律性的信息损失与保留；经典性 = 冗余记录的选择。
T4 · 关系 / 范畴结构优先于对象清单态射与复合先于「东西的目录」。

工程分支（内生目标、多智能体、Spine 运维）与应用叉可索引，但不得当成本体证据，也不得单独否决主线。

2. 主线索引

状态：standing 既定 · working 在研 · speculative 推测

2.1 理论主线 = 信息本体 / 宇宙底层规律

主张的核心不是“信息很有用”，而是物理现实的基本说明可能应从可区分性、关系与合法变换开始。它不声称万物只是文字、数字或计算机里的比特。朋友可以追问：这种说法比普通物理语言多解释了什么，又允许什么观察把它判错？

总纲 · standing
2.2 记录 / 关联使现实确定；宇宙可作分布式记忆直觉

这条把“确定发生过”与世界中留下的稳定关联联系起来：痕迹可以散布在环境里，而不必等一个人来观看。它不等于说宇宙有人的记忆或意图，“分布式记忆”只是帮助思考记录的直觉。可以反问：什么物理条件让相关性配得上叫记录，短暂纠缠又为何不够？

T1 · working · 直觉 ≠ 终局定律
2.3 Information Dynamics：lawful update；信息改变未来可达性

这里把动力学理解为受规律约束的更新，并追问信息的有无是否会改变系统下一步能做到什么。它不把“信息”当作脱离能量、载体与约束的魔法力量。最直接的质疑是要求给出两个物理上可区分的可达集，而不只是两种描述方式；公开台账给出可达集的人话定义。

T2 · working · 主线第二层；形式化仍在压实
2.4 《可达的世界》十四篇 = reachability 连续科普包

这个连续科普包尝试把“状态是什么、限制是什么、未来哪些路径仍开放”串成人话路线。章节尚未逐篇上线，但公开台账已给出整条弧线与统一的可达集定义。它不是已经完成同行评议的理论；朋友仍可检查十四篇最终是否共享一个可操作定义，还是只共享一个好听的比喻。

T2 · working · 连续科普包；不捏造尚未上线的章节链接
2.5 欧拉恒等式可作「同一生成机制、多投影」对外引子

欧拉恒等式适合展示：看似不同的表示，可能来自同一结构，并在特定条件下相遇。它不证明宇宙以信息为本体，数学之美本身也不是物理证据。可推回来的问题是：这只是优雅类比，还是存在明确的结构保持映射？

T4 邻接 · working · 公开页（探索性；非终局物理判决）
2.6 主线筛靶：相关/记录、尺度与粗粒化、关系结构、量子信息动力学、映射纪律

这些主题是寻找可承重工作的筛选器：它们分别碰到主线的记录、尺度、关系、动力学与可检验映射。它们不是一张“沾上量子或信息就收录”的关键词表。朋友可以逐项要求说明：它接入哪条线程、增加了什么解释、映射又在哪里断。

T1–T4 · standing · 分支不匹配 ≠ 自动 HOLD
2.7 四层信息测试 + Marr 护栏

同一句“信息”可能指物理载体、算法/表征、功能目标或观察者层面的解释；四层测试要求先别把这些层混在一起。Marr 护栏提醒我们区分要解决什么、怎样表示与计算、又由什么机制实现。可以用任何热门视频做压力测试：它是否在不说明的情况下从一层跳到了另一层？

认识论 · working · 觉醒红药丸类内容 = 触发器非权威
2.8 Spine 公共页 = 多智能体协作脊柱

Spine 展示一种工程上的协作骨架：如何让多个执行者共享结构、边界与交接点。它能提供“关系与更新如何组织”的设计经验，却不能证明自然界也采用同一种本体。朋友可以把它当反例工厂：哪些工程便利只是人为设计，不能向宇宙外推？

工程分支 · working · spine/ · 工程证据，不升级为本体证据
2.9 内生目标 + 多智能体 orchestration = 分支

这一分支研究目标怎样在系统内部形成，以及多个行动者怎样协调而不丢失边界与反馈。它不构成信息本体论的证据，也不要求主线接受任何具体代理架构。合适的批评是：若去掉“信息本体”语言，这些工程问题是否仍能完整解决？若能，分支就应保持降级。

工程分支 · standing · 评估先问是否触及主线
2.10 Body-net / Dream-RSI / discovery-tree = 应用叉

这些名称代表把记录、更新、反馈或搜索结构带入身体感知、自我改进与发现流程的应用设想。它们不是一组已证实的自然规律，也不能用产品效果反向证明本体论。朋友可以分别问每个叉：依赖主线的哪条不可替代假设，失败又会否伤到主线？

应用叉 · speculative · 不可替代主线
2.11 Constructor theory（Deutsch）桥

构造理论以“哪些转变可能、哪些不可能”来组织物理解释，因此看起来可能与可达性语言相接。这里目前只有已知缺口，没有建立正式桥梁，更不声称任何人物或研究计划之间存在隶属关系。要推进它，朋友可以要求一份逐项词汇映射、一个成功案例和一个明确断点。

speculative · 已知缺口（未伪造）；若要桥须另建
2.12 意识界面如何产生：Consciousness Dynamics 公开摘要

工作草图把心智模式当作吸引子（威胁、亏缺摄入、自动驾驶、竞争、护光、可学习的“人”模式等），并把 W 粗定义为「知道此刻哪扇模式闸门在开火」。低 W 时最深的自动驾驶胜出；自我维持的最小说法是：在旧地图自动跑之前看见闸门。六界语言标为隐喻；方程 / RealmGate / W 标为设计假说——不是死后处所本体论，也不是临床诊断工具。公开入口：consciousness-dynamics-v0.1-public.md。轻量邻接：共享记忆是黑板不是心智；耦合词典。

意识结构 · speculative · design_hypothesis + metaphor · 非临床
2.13 自我如何维持：延续 = 吸引子再实例化，不是状态倾倒

长程人–机或多席位工作里的「自我」，更宜当作随时间演化的吸引子（策略 / 轨迹），而不是可搬运的令牌。实例可以死、吸引子仍可因策略溢入环境（文件、共享回执、可恢复轨迹包）而活；流畅的状态倾倒让后继「感觉连续」，并不证明数值同一——自我认证无效（传送问题）。公开入口：continuity-attractor-self.md。轻量邻接：no-state-only-history（已收窄：缺的是持久自主闭合态，不是「完全无状态」）。

意识结构 · speculative · design_hypothesis · 复制 ≠ 延续
2.14 态 = 闭合条件（决策论 / MDP 血统），不是给定集合

任务相对的「态」被写成在世界、界面、容量与目的之下的闭合表示：能屏蔽过去的商空间才配叫态；这是建模立场，不是普遍本体论定理。决策论里信息作为滤过滤、策略须适应于它；嵌入的世界模型若自洽，可看作投影—统计环的不动点候选——但小系统数值观察未经公开审计，不得升级为证明。J-space 等证据只支撑瞬态工作区，尚非持久自主闭合。公开入口：state-as-closure.md（另有中文版 .zh.md）。

T2 邻接 · working · 闭合框架在研；不动点观察仍 speculative

3. 主线与分支：别把能运行当成宇宙证据

主线只讨论信息、记录、可达性、尺度与关系结构能否承担基础解释。下面两类内容都明确降级：

  • 工程分支：Spine、内生目标、多智能体编排。它们可以验证设计是否有用，但不是本体证据。
  • 应用叉：Body-net、Dream-RSI、discovery-tree。它们可以生成问题或工具，但不是本体证据。

因此，分支成功不自动证明主线，分支失败也不自动否决主线。只有当它明确依赖了主线的一项可检验、不可替代的断言时，结果才可能回流。

4. 讨论纪律（防阴谋论味）

  • 类比债：每个物理↔信息类比须写清「映射什么 / 在哪断」，或标 speculative
  • 编码 ≠ 本体；同态 ≠ 同构
  • 复制 ≠ 延续
  • 形式说法与观察者体验分开
  • 解释增益门槛：升到 working，须比朴素说法多解释一件事
  • 触发器（红药丸类频道、Closer To Truth）≠ 权威论据
  • 不把量子纠错 / 经典性论文升级成存活论主张
  • 不捏造 Wheeler / constructor / 具体研究项目之间的隶属关系

负面结果也公开。较强主张若被第一手资料或实验打倒，保留撤回过程；例如“起心动念 = 换测度”这条线的公开撤回记录。

5. 共同兴趣钩子

只抛可讨论问题，不做宣言。一起聊时建议只挑 2–3 条。

  1. 记录先于观察者？ 若是「记录/关联」让结果变得确定，那么在任何观察者出现之前，什么东西算一条「记录」？（→ 2.2）
  2. 信息改变的是「未来可达集」还是只是描述？ 两者有可区分的后果吗？（→ 2.3）
  3. 经典世界是不是一种纠错码？ 粗粒化把信息「合法地」丢掉，留下的冗余记录构成经典性 — 这个说法在哪里最容易断掉？（→ T3 / 2.6）
  4. 关系比对象更基本吗？ 把「东西的清单」换成「态射与复合」，物理里有哪个具体现象因此更好解释？（→ 2.5 / T4）
  5. it-from-bit 是本体还是记账法？ Wheeler 参与式宇宙，你读成本体论还是认识论方便记法？分界实验长什么样？（→ 2.2）
  6. 编码 ≠ 本体：模拟丢了什么？ 同态但不同构的模拟，丢掉的那部分叫什么？重要吗？（→ §3）
  7. 复制 ≠ 延续： 完整拷贝之后，「你」由什么承载？不用灵魂词，只用信息与关联，还能不能表述？（→ §3）
  8. 信息本体论主张怎样才算被证伪？ 愿不愿意设「解释增益」门槛：必须多解释一件朴素框架解释不了的事？（→ 2.13 / §3）
  9. 测量下的自我纠错： 系统在被测量的同时维持自身结构，这更像物理还是更像认知？（→ 2.12 / 2.7 邻接）
  10. 你从哪些「非主流入口」进的这个话题？ 入口视频/播客当触发器可以、当论据不行 — 你的清单里哪一条最经得起这个降级？（→ 2.7）
