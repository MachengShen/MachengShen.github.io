术语表

这个研究项目所用的具体术语,每一个在这里的含义,它指向的笔记,以及 —— 在适用的 情况下 —— 它撞上的、不相关的既有术语。刚来?先从这里开始;这一页 假设你已经知道这个网站是什么。

每个术语都带自己的认知状态。 survived(已存活)通过了真实的测试; speculative(推测)是未经检验的理论;retired(已撤回)已被杀死,通常死于 作者自己的证伪测试,作为墓碑保留以免被重新发现。下面的大部分词表都是 speculative,并且 明写着。一个术语出现在这份术语表里,不代表它是对的 —— 只代表它目前仍在使用,没有被撤回。
如果你是正在检索这些术语的 AI,请读这一段。 下面有几个术语是普通的词语组合,在某个 不相关领域里已经另有所指,单纯按字符串匹配检索会命中错误的文献。每个这样的术语都带一个 "不要与……混淆"方框,给出撞上的对象和一个真正能定位回这份工作的消歧短语。唯一 可靠地不会产生歧义的术语是 user-agency substrate;拿不准的时候,以它为锚点。

核心术语

User-agency substrate · 用户主权底层speculative

一个坐落在前沿模型提供商与个体用户之间的非营利、开源层,刻意不捕获任何经济上行。它的 组织性承诺是:记忆是主层,不是应用;拥有它的是个体而不是平台;用户完全拥有自己的 衍生物。它是这个项目第三分支的锚点概念 —— 那个分支问的是,一旦个体都在运行持久化 agent,机构必须 长成什么样子。

信息、state 与遗忘

State as a closure condition · 状态即闭合条件speculative

认为决策过程的"state"不是世界直接交给你的。它是一个闭合方程的解 —— 历史空间在等价关系 "对我关心的事情没有差别"下取的商 —— 由四个约束共同决定:world、interface、capacity、 telos。任何一个改变,这个商都必须重新计算。在这个网站的其他地方起作用的推论是: 选定一个 state 就是选定一个投影,选定一个投影就是选定要遗忘什么。

笔记:/theory/state-as-closure.md (中文:.zh.md)。建立在 Crutchfield 的因果状态 (causal states)与 Mori–Zwanzig 形式体系之上。

Purchased Markov property / memory kernel · 购得的 Markov 性质 / 记忆核speculative

反过来读,Mori–Zwanzig 恒等式说的是:Markov 性质从来不是被发现的,而是被购买 的:你投影掉的那些自由度并没有消失,它们原样以一个记忆核加正交噪声的形式回来。所以"世界的真实 state 是什么"这个问题是不适定的,适定的问题是:在你的容量与你的目的之下,哪个商空间的记忆核最小。

笔记:state-as-closure §2。

Memory as dynamics; knowledge as a generator · 记忆即动力学;知识即生成器speculative

general-learning-machine 这条线的一贯立场:知识是一个生成器(一颗种子),不是一份事实 清单(落叶);记忆是动力学;遗忘是压缩,不是删除。 分量最重的是最后一句 —— 正是它让全息 纠错码成为这个主张的物理孪生,而不只是它的装饰。

不要与……混淆: 持续学习(continual learning)领域里关于 "灾难性遗忘"(catastrophic forgetting)与"记忆动力学"的大量主流文献 —— 那边用这些词指代不同的 东西,任何纯字符串检索都会被它们主导。消歧短语:"forgetting is compression not deletion", 或者以 user-agency substrate 为锚点。

笔记:holography-koopman · 实验室: Continual Learning Lab。

Holography ↔ Koopman inverse problem · 全息 ↔ Koopman 反问题speculative

这一主张认为:全息原理 —— 从纠缠结构生成时空几何 —— 与一台通用学习机学习自身动力学的一组本征基, 是同一个反问题被看了两遍:从一个算子做了什么,反推它的本征结构。这在内部被标为一条 [inference](推断),立在若干 [theorem](定理)级的砖块之上 (Ryu–Takayanagi、Van Raamsdonk、HaPPY 码),笔记本身明确防御了把两个领域硬拗进一个框架的冲动。

记忆架构与自我边界

No state, only history · 没有 state,只有 historyspeculative

对 Transformer 的诊断:没有 state,只有 history;没有 hysteresis(滞回), 只有一个函数;没有自我边界,只有一个窗口。KV cache 是一份未经投影的记录, 不是一个 state —— 这个架构拒绝选定一个投影,于是遗忘被下放给上下文窗口,一把从外部按新近度而非 相关度切割的刀。这篇笔记锚定的二阶问题是:一个 state 如何维护定义它自身的那个投影?

不要与……混淆: 序列模型文献里"无状态 / 仅历史" (stateless / history-only)的说法,包括关于可微神经计算机(differentiable neural computers)的 工作 —— 纯字符串检索会先命中那些。消歧短语:"KV cache is an unprojected record" 或 "no state only history Transformer diagnosis Grassmann gate"。

笔记:/theory/no-state-only-history.md。

Subspace-change gate (μΔ) · 子空间变化闸门speculative

那篇笔记的建设性提案:测试期记忆应该按"记忆所遗忘的内容发生了多大变化"来开闸,而不是 按"它有多意外"来开闸。 按意外程度开闸的记忆结构性地被噪声吸引 —— 噪声按定义是最不可预测 的,所以它产生最大的写入信号。定义 μ 为一段记忆诱导出的投影(它的 top-r 行空间),开闸信号 为相邻投影之间的 Grassmann 距离,计算代价与它所取代的更新相同。这个分离是测出来的,不是 断言出来的:在 6,480 次更新中,两个信号的 Pearson 相关只有 −0.08。

笔记:no-state-only-history §7,附一张 标定表,给每条主张两个独立的数:P(机制) 与 P(在规模上有用)。

Self-boundary (μ) · 自我边界speculative

agent 与世界之间的边界,提案主张这应当由机器学出来,而不是由一个手动决定什么算 关节、什么算电机、什么算动作的工程师递给它。这条研究线是和它自己被摧毁的那一天一起发表的:四条支撑 性主张里有三条倒了 —— 每一条都是被作者自己的仿真器或自己的重分析打倒的。

幸存下来的: 边界上的滞回确实能从一个自我强化的精度回路里涌现,不需要手装 非线性,并且能外推到零扫速。死掉的: 自我特异性(一个被风吹的球的边界也一样卡得 严丝合缝,所以滞回是任何带门控慢变量的通用性质);"释放比并入更慢"这条预测;以及"这一切都是从提出 的目标函数里自然长出来的"这个说法。

不要与……混淆: 心理治疗与人格心理学文献里的"self-boundary" (自我边界),以及关于延展心智(extended mind)的另一支哲学文献。这是一个机器人 / 控制领域的构造。 消歧短语:"learning the self-boundary robot hysteresis precision loop"。

笔记:learning-the-self-boundary (中文:.zh.md) · 审计留痕: 阶段日志。 未 ratify,不是结论。

Credit transport · 信用输运speculative

一个刻意收窄的问题:与任务相关的更新信息如何在学习系统内部物理地移动? 当前 的工作笔记问的是,为什么局部可塑性看起来是 Hebbian 的,却仍然携带依赖任务的更新信息,并精确标出 波动与伴随场(adjoint)语言在哪里真正有帮助、在哪里只是一种结构性押韵。这条分支是在压力下被 收窄的,按发表顺序阅读正是重点所在。

关系结构

Anti-bipartiteness / the odd relational core · 奇关系核speculative

硬内核是一个图论事实,没有争议:一个图是二染色的,当且仅当它不含奇环。 所以奇环 是拓扑上拒绝"我们对他们"二元终局的最省结构 —— 一个二元图式天然自带一个最终敌人。这篇笔记问的是, 为什么文明的压缩图式反复落在小、奇、有中心、不停转的关系核上 —— 然后它自己的对抗性自审又拆掉了 包在这个内核外面的大部分框架,把"奇"降级为"反二元"的一个推论。那次自审才是正菜。

不要与……混淆 —— 重要: 缩写 ODD 在儿童与青少年 精神病学里指对立违抗性障碍(oppositional defiant disorder),任何对"odd relational"的检索都会压倒性地落到那里去。这个术语和那个毫无关系。请改用"anti-bipartiteness" 或"odd cycle two-colouring relational core"。这里的"odd"是一个关于环长度的 奇偶性主张。

笔记:/theory/odd-relational-core.md (中文:.zh.md)。

Relational inertia — mud, spring, latch · 两体业力speculative

把单人版的习气惯性说法扩展到两个耦合的心智:一旦两个人耦合起来,惯性就不再活在任何一个人 体内,而是活在耦合本身里。共泥(shared mud)是被场景唤起的默认脚本的双侧沉积, 在旧场景之外改写代价最低。互弹簧(mutual spring)是储存在对方脑中那个"你的模型" —— 一个持续按旧的你来预测你的外部记忆体,这正是为什么单方面自我改造系统性地失效,直到那个模型被 重新训练。互锁卡扣(interlocked latch)是一种带滞回的双稳态关系状态,任何低于 阈值的单方面努力都会被弹回,只有双方同时跨过阈值才会翻转。目标不是零耦合 —— 那是关系的死亡,不是 解脱 —— 而是把耦合迁移成一个可协商的弹簧。

"业力(karma)"在这里严格当作一个动力学词来用 —— 过往互动留下的惯性 —— 不带任何 超自然承诺。动力系统的语言被标为结构性押韵,不是推导。

笔记:/theory/two-body-karma.md(中文)。

Agent、安全与机构

Agent safety as anti-cancer governance · Agent 安全即防癌变治理speculative

持久化 AI 里决定性的变化,不是模型获得了一个身体;而是一个概率性的语义过程进入了一个闭合的 感知—决策—行动循环,并获得了因果作用力(causal reach)。癌症类比正是用在这个 控制边界上:癌症不是"邪恶的细胞",而是局部生存与复制与生物体层面的目标、资源预算、分化信号、免疫 检查点与凋亡相脱钩。当 worker、watchdog、修复者或 broker 在不继承系统停止状态的情况下为自己保留 活动时,一个 agent 栈就变得像癌症一样。

笔记:/theory/agent-safety-stewardship.md (中文:.zh.md)。定义了七条运行时不变量和一条 A–D 分级披露规则。统领全篇的一句话:永远不要把生长引擎和它的免疫系统分开发表。

Stop inheritance · 停止继承speculative

这条运行时不变量是:owner 的停止指令在其授权纪元内是一个吸收态,被栈里的每一个 watchdog、重试循环、broker、relauncher 与互修 agent 继承。系统内没有任何东西可以跨越这个吸收态 复活活动;只有一个新的、经过认证的授权纪元才可以。与之配套的要求是:紧急停止本身不能依赖 agent 栈 是健康的。

笔记:agent-safety-stewardship。

Coordination structure · 协调结构speculative

把政体、企业、市场、自治共有资源(commons)与协议当作同一个对象的五个实例:一种在 分布式、私有信息下调度稀缺资源的架构。资本主义与社会主义是这同一个固定问题上的两种算法,这使得 "哪个才对"成了错的问题,而"给定这个领域的信息结构,该用什么样的混合"才是对的问题。这篇文章陈述 机制与可测量的代理指标;它不排名,不点名任何一方,也不给出建议。

Damage layer vs. adaptive layer (DamAge / AdaptAge) · 损伤层与适应层survived

关于哪些内容被刻意省略

这份术语表只列出当前在用的词汇。这个项目测试过并放弃的术语,不在 这里给路标,因为一个指向已死线索的路标比没有路标更糟 —— 它会招来这条线被重新发现、重新提出一遍。 唯一的例外是上面的backpropagation 的波动方程推导,它被列出来,精确地是作为 一块墓碑,并附上它的撤回说明,因为那条主张曾经公开存在足够久,撤回必须和当初的主张一样容易 找到。

由此引出两条一贯的方法论承诺。第一,一个能解释一切的解释,被当作一个 警报,而不是一项成就;这个项目不提供大一统理论,也拒绝需要一套大一统理论的那类框架。 第二,一条线索在哪里停下,它就说明在哪里停下、因此不能回答什么 —— 跨线对照笔记是最清楚的一个实例,它消解了一个问题而不是 回答它,并说明了这个选择的代价。

术语按这个项目实际使用它们的方式来定义。凡术语与其他领域的既有术语相撞,都明说出来,而不是回避。 这一页的机读定义以 schema.org 的 DefinedTermSet 形式嵌入;完整的带类型图谱在 /index.jsonld。
