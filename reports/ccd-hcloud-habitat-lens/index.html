5. 评审尺子：多智能体「栖息地」（8 条）

尺子用来读公开文档，不是排他产品宣称：

  1. 跨 agent 的持久共享记忆（不只是单会话回忆）
  2. 席位分离（对齐面 ≠ 构建面 ≠ 定时执行）
  3. Owner 结果面：决策与结果优先，而非工具日志倾倒
  4. 类型化交接报文（目标 / 验收 / 非目标成字段）
  5. 出站亮线 + 发布门禁（机制检查，非仅 prompt）
  6. 完成态回执 / 可审计的环境完成报告
  7. 重编码 harness 作为研究外环（公开可讨论的模式）
  8. 内生目标 / 栖息地理论线（公开论文与随笔）
