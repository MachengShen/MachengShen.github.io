Sophon / 智子

A personal multi-agent system — not a chatbot app.

Sophon (Chinese: 智子) is the name of the agent stack Macheng Shen runs day to day. The English name is for people who should not have to pronounce pinyin; the Chinese name stays 智子.

human-readablespeculative · check falsifiers

One person. Many AI seats. One shared memory. Hard safety gates. The point is less babysitting — not more chat windows.

What it is, in one screen

  • Shared Memory Hub — standing decisions and receipts live outside any single chat, so new agents can recover context.
  • Seats, not clones — a frontstage experience seat (e.g. Grok Bot), cloud/code executors, and always-on hosts each do different jobs.
  • Standup vs private lanes — group chat is for alignment; heavy builds stay in private lanes.
  • Safety as code — consequential actions go through gates (propose vs execute vs speak-as-owner), with receipts.

What it is not

  • Not a consumer product you can install today as an app-store download.
  • Not “one mega-chat that does everything.”
  • Not a claim that the fleet source code is all public (public research + protocols yes; private runtime stays private).
