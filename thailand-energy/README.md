# Thailand energy study — static site

- `index.zh.html` — Chinese (primary). `index.html` — English (same content). Language toggle in header.
- Plain static HTML + `style.css`; no build step, no external scripts/fonts/trackers. Works from any static host or subfolder (all links relative).
- `assets/` hourly evening-peak charts (SVG, EN + ZH) generated by `scripts/hourly_profile.py`.
- `data/`, `model/`, `scripts/`, `review/` — downloadable data and scripts referenced on the page. Run scripts from the site root (Python 3 + pandas; review cost curve also needs pyyaml + matplotlib).
- `research/INSTITUTIONS.md (EN) / INSTITUTIONS.zh.md (ZH)` — who plans Thailand's power system (verified sources only).
- Hourly data: Bunnak (2025), Zenodo 17109911, CC-BY-4.0 — attribution is on the page.
- Last updated 2026-09-26. Not published anywhere by the author of these files.
