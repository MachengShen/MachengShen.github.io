The map

One question, asked at six depths: what makes a future reachable, and what does a finite physical system have to build inside itself in order to reach one.

Read the state before the title. Every entry below is marked survived (it has passed a real test), speculative (untested, interesting, unearned), or retired (killed, usually by its own author). Retired work is not deleted. It stays at its original URL so that it is not rediscovered and proposed again — including by whoever proposed it the first time.

The six sections run from the least agent-like layer to the most, but nothing here is a prerequisite for anything else. Pick the layer you already argue about and start there. /llms.txt is this same index for machines, and 中文版在这里.
