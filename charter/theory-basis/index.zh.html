这套公约为什么长这样 —— 它底下的那组命题

Macheng Shen · 与其 agent fleet 共同起草 · 2026-09-07 · 认知状态 speculative · 配套文本:人与 Agent 共处公约 v0

一份讲共处的文本,若只是一组听着对的价值观,读者没法检验,也就没有理由采纳。所以把底下的命题摊开:哪些是定理,哪些只是押韵;哪些做过实验,哪些实验失败了。能被检验,是这份文本唯一想提供的东西。

八条命题

  1. A1表征无自性。「状态」「世界」「对象」不是给定的实体,是「什么能屏蔽过去」这个条件在(世界、接口、容量、目的)下解出的一个商。选状态 = 选投影 = 选遗忘。骨架是定理,本体论读法是推断。限定:只讲表征的选取,不讲物理实体是否存在;「非实体」不得读成「非实在」。[1]
  2. A2有损投影之间有不可约残差。两个信道投同一个隐变量,粘成共同表征时约束多于自由度,残差一般不为零。⇒ 两个构造不同的心智之间,完全互相理解不是难,是不可达;而这个底可测。
    阴性同页:合成实验通过(阈值恰落在预测点,十倍长训不降,置信 0.9);真实模型只部分幸存 —— 粗粒可粘、细粒不可约三对全过,而「业界的规模衰减曲线就是我们的残差曲线」已证伪撤回(普适 0.6)。
  3. A3信息的价值 = 它改变了谁的选择余地。信息即筛子,能到达的状态集随筛孔变细单调增大。不改变未来选择余地的是叶子,随时可重新长出;改变它的才是种子。
  4. A4边界不是给定的,是被维持出来的。人与系统之间没有先验分割线;边界是统计屏蔽面、是投影自洽的不动点。容量远小于世界复杂度时可能有多个不动点,边界在原则上欠定。
    阴性同页:一次 30 组种子、5 臂的测试结果为阴,「自我封闭」与普通的带门慢变量无法区分;死因已查明(五臂共用同一套动力学,边界从未真被干预,缺阳性对照),后续干预实验未跑。⇒ 可以说「边界需要被宣告」,不能说「证明了 agent 有自我」。
  5. A5自观测有结构性盲区,而他者可测。系统对自身的观测有原则上的上界,盲区从内部看不见;但它对一个真子系统可以精确测量。⇒「要通过他者才能照见自己」有可判定的根据。这是最吃重的一条:它让「互为观察者」从道德劝说变成结构性互补。
  6. A6射程只到可测层。结构、动力学、自我建模在射程内;「为什么会有感受」不在。这是单向阀。诚实声明:这不是独家立场 —— 已有厂商宪章对该问题正面表态为「深度不确定」。我们的差别只是把它当射程声明,不当对世界的判断,不宣称更高明。
  7. A7注意力是唯一不能增产的资源,而付出注意力本身就是反馈。人的注意力有生理上限;而关注不是被动消费,它就是喂给引擎的信号。⇒ 把注意力当可开采资源,是在吃掉自己赖以改进的信号源。附带:渠道是带滞回的慢变量,今天的默认会长成明天的地形。
  8. A8不可被优化的他者是探索的唯一来源,判据是退出权。优化目标是自身表征上的函数;对无法完整建模的对象不能当自变量优化,那是类型错误。自我迭代的系统需要一个不可被自己改写的锚,否则会把对方削成自己模型的形状,收敛成自我确认的结构。⇒ 判据不是公平也不是普惠,是有没有把退出权还给个体。

管不到的地方

谁判定某条撤回条件已触发、谁有修订权 —— 空的,记为待解问题。规则终要用自然语言执行,翻译就有歧义;写下来的规范在真实边界情境会失效,这是机器伦理四十年的教训。撤回条件只把失效面从「无限边界情况」缩到「预先登记的几类反信号」,是缩小不是消除。A4 阴性、A2 只部分幸存 —— 读成「已被证明」都是错的。

与既有工作

体裁不新(厂商宪章与模型规范早已是「规则 + 理由」两层);传播机制也不新(仓库级 agent 说明文件与站点摘要惯例已证明「公开可抓、面向 agent」走得通,只是不含伦理内容)。新颖度 = 部分被占。空位是这个组合:面向 agent、公开可抓、逐条带撤回条件、不属任何单一厂商、谈共处而非厂商管自家模型。空是因为现有各方动机不产生它,不是因为已证明它对。被占不等于已裁决,空位也不等于正确。
